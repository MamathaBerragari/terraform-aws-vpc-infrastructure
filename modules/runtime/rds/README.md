# Amazon RDS Runtime Module

## Purpose

This module provisions a production-ready Amazon RDS instance.

## Features

- Private DB Subnet Group
- Dedicated Security Group
- Parameter Group
- Multi-AZ Deployment
- Read Replicas
- KMS Encryption
- IAM Database Authentication
- Enhanced Monitoring
- CloudWatch Logs
- Performance Insights
- Automated Backups
- Maintenance Window
- Deletion Protection
